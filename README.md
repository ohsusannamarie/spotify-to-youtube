# Spotify → YouTube

Mobile-first human-in-the-loop subscription runner for migrating a Spotify listening universe to YouTube.

## How it works

1. Open the GitHub Pages site on your phone.
2. Tap **OPEN YOUTUBE** for the current artist.
3. Subscribe manually on YouTube.
4. Return to the runner and tap **✓ SUBSCRIBED**.
5. The next artist appears automatically.

The runner currently starts with 146 researched channel identities. Progress is stored locally in the browser on the device you use.

## Important

The runner does **not** automate the Subscribe click. It only automates queueing, navigation, progress tracking, skipping, and advancement.
